# Hotel Room Booking and Customer Management System

A single-user, menu-driven console application written in **C (C11)** for a Programming for Problem Solving (PPS) project.

The program helps a hotel manage rooms, customer records, bookings, cancellations, checkout, and billing. It stores records locally in files so the information can be loaded again when the program starts.

## Features

- Display available hotel rooms and their categories
- Register customers and store their contact details
- Add, edit, and deactivate rooms
- Create bookings with date validation
- Prevent overlapping bookings for the same room
- Display and search customer and booking records
- Cancel bookings with a configurable cancellation-fee percentage
- Check out customers and record actual stay and service usage
- Generate bills with room, meal, laundry, discount, and GST calculations
- Save and view bill history
- Validate common user inputs and handle file errors

## Technology

- Language: C
- Standard: C11
- Interface: Console / terminal
- Libraries: C standard library only
- Storage: Local binary data files and a text bill-history file

## Requirements

You need a C compiler that supports C11, such as GCC.

Check whether GCC is installed:

```bash
gcc --version
```

## Compile and run

### Windows (VS Code terminal / Command Prompt)

```bash
gcc -std=c11 -Wall -Wextra -pedantic team10.c -o hotel_system.exe
.\hotel_system.exe
```

### Linux / macOS

```bash
gcc -std=c11 -Wall -Wextra -pedantic team10.c -o hotel_system
./hotel_system
```

Run the program from the folder containing the executable. The program will create its local data files as records are saved.

## Local data files

The application uses these files in its working directory:

- `customers_v2.dat` — customer records
- `bookings_v2.dat` — booking records
- `rooms_v2.dat` — room records
- `hotel_settings_v2.dat` — hotel settings
- `hotel_bill_history.txt` — readable bill history

These are generated by the application at runtime and are excluded from Git by `.gitignore`.

## Notes

- This is a **single-user, local console application**. It is not a web application and does not provide multi-user or network access.
- GST and discount values in the source are sample project settings, not official tax guidance.
- Binary data files are intended to be read by this program version and should not be treated as a portable database format.
- The project is provided as an educational PPS exercise.
